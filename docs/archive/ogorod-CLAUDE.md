# Огород (рабочее название)

Браузерная 3D-игра: уютный огород днём, лёгкая оборона от милой нечисти ночью. Прототип для себя.
Стек: Three.js + Vite. Публикация: GitHub Pages.

## Мир и сюжет (черновик, может меняться)
- Действие происходит на летающем острове. Внизу и вокруг — туман.
- По ночам из тумана поднимается нечисть: призраки, скелетики и прочие духи, милые, в стиле кози-игр.
- Главный герой — енот. Позже можно добавить выбор других животных (скины на одной схеме: уши, хвост, окрас).
- Уютный детектив: откуда туман, почему остров летает, кто такие духи. Разгадка — через исследование.
- Финал добрый: примирение, а не уничтожение.

## Игра
- Изометрия, ортографическая камера, фиксированный ракурс (без вращения), зум не нужен.
- **День — огород:** посадить → полить → вырастает → собрать → отнести в корзинку → монеты → семена в магазине.
- **Ночь — оборона:** спелые растения, которые не собрали, становятся «башнями» и отпугивают нечисть.
  - Нечисть не убивает и не уничтожается: она пытается утащить урожай, башни её прогоняют.
  - Проигрыша нет. Худший исход ночи — потерял немного урожая.
  - Прогнанный дух оставляет **огонёк** — второй ресурс.
  - Растение-защитник через несколько ночей отцветает и оставляет семена.
- **Два ресурса, оба нужны:** монеты (продажа) → обычные семена; огоньки (оборона) → редкие семена и дерево улучшений.
- У растений разные роли: одни выгодно продавать, другие хорошо защищают. Выбор «продать или оставить» не должен быть очевидным.
- Растения растут при закрытой игре (досчитываем по времени), но ночные набеги идут только во время игры.
- Сложность везде низкая: и прогрессия, и оборона, и головоломки.

## Управление (гибридное)
- Клавиатура: WASD / стрелки — ходьба, пробел — действие на клетке перед персонажем, 1–4 — инструменты.
- Мышь / тап: клик по клетке — персонаж идёт туда и выполняет выбранное действие.
- Панель инструментов внизу экрана. Крупные кнопки — игра должна работать на телефоне.

## Визуальный стиль
- Геометрия: примитивы (кубы, цилиндры, конусы), без текстур и сложных моделей.
- Постобработка, переключается клавишей P (временно, для сравнения):
  1. выкл — чистая сцена
  2. пиксели — рендер в низком разрешении, растягивание без сглаживания
  3. ASCII — символы по яркости `.:-=+*#@`
- Палитра строго монохромная оранжевая, все цвета приводятся к ближайшему:
  `#1a0a00 #4a1c00 #8c3a00 #d9661a #ff9933 #ffd9a0`
- Ночь — те же оттенки, но темнее; нечисть и огоньки светятся самыми светлыми.
- Панель с ползунками (lil-gui) для настройки стиля. Открывается клавишей G, в финале уберём.

## Сохранение
- Автосохранение в браузере (localStorage), чтобы ничего не терялось.
- Кнопки «Сохранить в файл» / «Загрузить из файла» (JSON), как в обычных играх.
- В Chrome на компьютере — перезапись одного и того же файла; на телефоне и в Safari — скачивание нового файла.
- В файле хранится время сохранения, чтобы досчитывать рост.

## Технические правила
- Код разбит на понятные файлы (сцена, персонаж, грядки, ночь, постобработка, интерфейс, сохранение).
- Все игровые числа (скорость роста, цены, сила башен, стоимость улучшений) — в config.js, чтобы я мог менять их сам.
- Данные растений (название, роль, цена, время роста, сила защиты) — в одном списке, чтобы добавлять новые без правки логики.
