# Осенняя ферма 2

Браузерная игра: днём уютный огород на летающем острове, ночью лёгкая оборона урожая от милой нечисти. Мир реалистичный, а герой-енот, растения и эффекты пиксельные.

**Играть:** https://p4rzifalus.github.io/osennyaya-ferma-2/

Первая, монохромная версия лежит в соседней папке [`osennyaya-ferma`](../osennyaya-ferma).

## Как запустить у себя

```bash
npm install
npm run dev
```

Игра откроется на http://localhost:5174, если запускать через превью Claude (конфигурация «ferma-2» в `.claude/launch.json`). Обычный `npm run dev` берёт порт 5173. С телефона в той же Wi-Fi сети открывай адрес из строки `Network` при запуске сервера.

- `npm run build` — собрать игру в папку `dist`
- `npm run preview` — посмотреть собранную версию

Публикация автоматическая: после `git push` в `main` GitHub сам собирает игру и выкладывает её на Pages (`.github/workflows/`).

## Что где лежит в коде

| Папка / файл | За что отвечает |
|---|---|
| `src/config.js` | **Все игровые числа и список растений** (`PLANTS`), качество графики (`QUALITY`). Менять можно самому |
| `src/main.js` | Запуск игры и главный цикл |
| `src/game.js`, `src/garden.js` | Правила игры: деньги, грядки, рост, сбор. От картинки отделены |
| `src/night.js`, `src/daytime.js` | Смена дня и ночи, ночные набеги |
| `src/hero.js`, `src/input.js` | Герой и управление |
| `src/scene.js`, `src/island.js`, `src/decor.js`, `src/grid.js` | Сцена, летающий остров, декор, клетки |
| `src/ui.js`, `src/menu.js`, `src/text.js` | Интерфейс, стартовый экран и меню, тексты и окончания слов |
| `src/save.js`, `src/save-file.js` | Автосохранение в браузере и сохранение в файл |
| `src/render/` | Картинка: свет, день-ночь, частицы, погода, постобработка, уровни качества, панель настройки (клавиша G) |
| `src/world/` | Объекты мира: туман, духи, огоньки, фонари, атаки растений, лучи света |
| `src/art/` | Загрузка картинок из `art/` и генерация заглушек, пиксельные спрайты |
| `src/audio/` | Звуки и музыка, синтезируются в коде |
| `art/` | Свои текстуры (реалистичная часть мира) |
| `public/` | Иконки сайта, картинка для превью ссылки, шрифты |

## Стек

Three.js (WebGL2) + postprocessing (pmndrs) + Vite. Сервер не нужен: сохранения хранятся в браузере игрока или в файле.
